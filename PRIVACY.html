Privacy Policy

This application (clipbot) is a personal automation tool that monitors public livestreams and generates short-form video clips for personal use.

Data Collection

This application does not collect, store, or share personal data from end users. It processes only publicly available livestream content.

TikTok Integration

This app uses the TikTok Content Posting API solely to upload video clips generated from public livestreams. No TikTok user data is stored beyond what is necessary to complete the upload.
